    ‘강도’는 같은 팀원·상대 조건에서 이 브롤러가 들어갔을 때 팀 승률이 평균보다 몇 %p 높은지 추정한 값입니다. 판수가 적으면 0 쪽으로 줄여서 추정합니다.

    어떻게 추천하나요?

    1. 데이터

    Brawl Stars 공식 API에서 공개된 랭크전(3대3) 결과를 1시간마다 모읍니다. 랭킹 상위 플레이어에서 시작해 그들과 함께 경기한 플레이어로 넓혀 가며, 최근 30일치만 씁니다. 플레이어 태그는 저장하지 않습니다.

    2. 승리 확률 모델 (맵마다 따로)

    logit P(우리 승) = Σ 강도(우리) − Σ 강도(상대) + Σ 시너지(우리 쌍) − Σ 시너지(상대 쌍) + Σ 카운터(우리 vs 상대)

    • 강도: 릿지(L2) 로지스틱 회귀로 추정합니다. 판수가 적은 브롤러의 극단적인 승률이 0 쪽으로 줄어듭니다.
    • 시너지·카운터: 강도 모델이 설명하지 못한 승패를 쌍별로 추정하고, 통계적으로 유의한 쌍(|z| ≥ 3)만 씁니다. 가짜 데이터 검증에서 이 기준이 따로 떼어 둔 데이터의 예측 오차를 가장 작게 만들었습니다.

    3. 추천 탐색

    남은 픽을 끝까지 내다보는 미니맥스 탐색입니다. 상대도 이 모델 기준 최선으로 고른다고 가정하고, 각 단계에서 즉시 이득이 큰 후보 5~12명만 펼칩니다(빔 탐색). 그래서 결과는 근사 최선입니다.
